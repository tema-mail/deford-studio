# deford-studio

Перенос главной страницы deford-studio.ru с Тильды на код (Astro + чистый CSS).

## Где смотреть

Сайт: **https://deford.ru/** (домен на reg.ru, DNS → GitHub Pages; старый адрес
tema-mail.github.io/deford-studio/ переадресует сюда) — пересобирается
автоматически при каждом пуше в `main` (`.github/workflows/deploy.yml`).
Копия закрыта от поисковиков через `robots.txt`, canonical ведёт на боевой домен.

Пути в разметке корневые. Префикс подпапки `/deford-studio` (`scripts/rebase-dist.mjs`)
сборка ставит, только если у Pages не задан свой домен; с deford.ru пути остаются
корневыми.

## Запуск

```bash
npm install
npm run dev        # http://localhost:4321
npm run build
```

## Сверка с оригиналом

```bash
node scripts/shots.mjs https://deford-studio.ru/ ref    # эталон
node scripts/shots.mjs http://localhost:4321/     new   # копия
```

Скриншоты пишутся в `reference/` на ширинах 1440 / 1200 / 980 / 768 / 640 / 480 / 375.

## Что осталось от Тильды

Форма попапа отправляется на `https://forms.tildacdn.com/procces/` с теми же
служебными полями, что и раньше — заявки продолжают приходить на прежний адрес.
Это единственная оставшаяся зависимость: при полном отказе от Тильды в
`src/components/Popup.astro` нужно подставить свой обработчик.

## Чем проверялось совпадение

Высота страницы и размеры каждой секции сверены с живым сайтом на ширинах
1440 / 1200 / 980 / 768 / 640 / 480 / 375 — совпадают до пикселя.

```bash
node scripts/compare.mjs "#deford-hero-v5" hero 375   # одна секция на обоих сайтах
node scripts/shots.mjs http://localhost:4322/ new     # вся страница
```

## Лендинг «Цветы» — /flowers

Перенос `targetfactory.ru/flowers` (Тильда) 1:1. Копия:
**https://deford.ru/flowers/**

- Свой layout `src/layouts/Flowers.astro` (шрифты Oswald + Montserrat, метаданные
  оригинала, плавный скролл по якорям) и база `src/styles/flowers.css` — сброс
  платформы с моделью `content-box`, на ней построены размеры всех секций.
- Секции — `src/components/flowers/`, перенесены из исходной разметки страницы
  (до выполнения скриптов), поэтому анимации стартуют с чистого состояния.
- Служебные блоки платформы переписаны своим кодом по замерам: попап заявки
  (`Popup.astro`, бывший Zero Block), документы (`DocPopups.astro`, тексты —
  `src/data/flowers-docs.json`), уведомление о cookie, скролл.
- Картинки — `public/img/flowers/`, имена с префиксом из пути CDN, чтобы
  одноимённые файлы не перетирали друг друга.

Сверено: высота страницы на 1440/1200/980/768/640/480/375 совпадает с оригиналом
точно; каждая секция, попап, документы, cookie и переходы по меню — отдельно.

Отличия от оригинала:
- поле телефона в попапе — без выбора страны и маски платформы;
- форма отправляется на `forms.tildacdn.com` с прежними служебными полями.

```bash
REF=https://targetfactory.ru/flowers NEW=http://localhost:4322/flowers \
  node scripts/compare.mjs "#rec4182830401" steps 375
```

Новые блоки, которых нет на оригинале (стоят после «Этапов работы»):
- «Интернет-магазин» — `src/components/flowers/Sites.astro`; цифры кейса примерные
  (500 заказов, 7%, 1 200 ₽) — заменить на цифры реального кейса;
- «Аудит сайта» (лаймовый призыв) — `src/components/flowers/SitesCta.astro`.
Отдельно оба блока: https://deford.ru/drafts/flowers-sites/

## Главная Target Factory — /targetfactory

Тексты и порядок блоков — с `targetfactory.ru`, дизайн — система лендинга
«Цветы» в красно-чёрной гамме оригинала. Копия:
**https://deford.ru/targetfactory/**

- Layout `src/layouts/TargetFactory.astro` (метаданные оригинала, появление блоков,
  скролл по якорям), система стилей `src/styles/tf.css`, блоки — `src/components/tf/`.
- Переделано по решению Артёма: второй блок (шесть фактов) — без руки-робота
  и огромных цифр; «Почему выбирают нас» — без лампочек, в двух вариантах
  (`WhySimple` и `WhyAnimated`, оба на странице с подписями — после выбора один убрать).
- Формы: попап заявки — одна форма вместо четырёх, номер формы оригинала по хуку
  ссылки; квиз расчёта — 5 шагов, одна заявка с полями оригинала. Отправка — на тот же
  адрес приёма заявок Тильды, что у оригинала.
- Видео — плееры VK Видео оригинала; картинки сжаты (WebP/JPEG) в `public/img/tf/`.

## Чего на странице ещё нет

Ссылки «Пользовательское соглашение» и «Политика конфиденциальности» в подвале
и попапе ведут на `/agreement` и `/policy` — эти страницы ещё не перенесены,
на копии отдают 404.
